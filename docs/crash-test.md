# 崩溃缺陷复测记录

## 背景

官方版二进制（md5 `d0b7c823`）存在：**纯 HTTP + 非空 Host 头访问 TCP 5588 → SIGABRT**。

## 复测过程（补丁前官方版）

- 进程：web PID 51467（`-r web -m tun -p 5588`）
- 触发：`curl -H 'Host: 1.2.3.4' http://127.0.0.1:5588/`（任意路径均可）
- 结果：
  - daemon 日志出现 `sig:6 Aborted`（SIGABRT），coredump 落盘
  - 连续 5 次 HTTP 全部崩溃（复现率 10/10）
  - daemon 自动 fork 自愈（web 51467→64714→65257），WS 101 恢复、手机轮询不受影响
  - systemd NRestarts=0（崩溃发生在进程内，未触发 systemd 级重启）

## 补丁后复测

- 二进制：md5 `b1c3b473`（patch#2）
- 触发：同条件纯 HTTP ×10
- 结果：全部返回 404、web PID 稳定无重启、崩溃计数零新增、WS 101 正常

## 结论

- 崩溃与"绑定/加速"功能**正交**——补丁不影响已成功的绑定与加速；
- 触发门槛极低（任何健康检查/端口扫描/误连都会崩），带病运行会持续落 core 占盘，**补丁必须加**。
